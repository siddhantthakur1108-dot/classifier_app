ML ASSIGNMENT 2 - PHASED LEARNING REFERENCE

This package is a worked example for learning. The assignment permits AI for
learning support, not direct copy-paste submissions. Understand and develop your
own work, run it in BITS Virtual Lab, and write your own observations. The bundled
reference metrics were computed outside BITS Lab. No GitHub or live app link has
been created for you.

SETUP BEFORE THE SIX PHASES

1. Extract the entire ZIP. Keep all files together in steel_faults_learning.
2. Open the notebook ML_Assignment_2_Phased_Guide.ipynb INSIDE that extracted
   folder. A notebook downloaded alone cannot import the companion project files.
3. Use Python 3.12. In a Linux/Bash terminal, from the extracted parent folder:

   cd steel_faults_learning
   python3.12 -m venv .venv
   source .venv/bin/activate
   python --version
   python -m pip install -r requirements.txt

   Windows PowerShell environment setup, after opening the project folder:

   py -3.12 -m venv .venv
   .\.venv\Scripts\Activate.ps1
   python --version
   python -m pip install -r requirements.txt

   For the notebook, also run:

   python -m pip install -r requirements-notebook.txt

   Select this Python environment in the lab's Jupyter/VS Code notebook interface.
   Dependency installation is a prerequisite even though requirements.txt is
   discussed in Phase 4 of the assignment.

PHASE 1 - DATASET CHOICE

Read README sections a and b and the notebook's first phase. The example uses UCI
Steel Plates Faults: 1,941 rows, 27 input features, seven fault classes.

   python prepare_data.py

Check class counts and explain why every original target indicator is removed
from the inputs. Keep the UCI source attribution.

PHASE 2 - FIVE MODELS AND SIX METRICS

Study ml_core.py and train.py; make decisions you understand and can explain.
All models use one common held-out split. Five-fold training-only CV selects a
baseline using macro F1. The test set is not used to tune parameters.

Run with a truthful description of your actual environment:

   python train.py --execution-context "My actual execution environment - replace this description"

ONLY when you are actually executing in BITS Virtual Lab, use:

   python train.py --execution-context "BITS Virtual Lab"

The context text is not evidence of lab execution. Capture a genuine screenshot
separately. Training regenerates test_data.csv, model/, and results/. Compare all
five models on Accuracy, AUC, Precision, Recall, F1, and MCC. Inspect class errors.
